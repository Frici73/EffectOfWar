# EffectOfWar

Az EffectOfWar egy helyi multiplayer játék, amely egy gépen fut 1–2 játékos vagy játékos és gép között.

A játékban különböző karakterek kombinálásával kell legyőzni az ellenfelet.  
A karakterek kasztokba vannak rendezve, és rendelkeznek „subclass” besorolással, amely jelenleg nem befolyásolja a játékmenetet, csak a döntéshozatalt segíti.

---

# 🚀 Telepítés

Az **EffectOfWarLauncher** szükséges a játék futtatásához.

1. Töltsd le és helyezd el egy tetszőleges mappába
2. Indítsd el a launchert
3. A program automatikusan kezeli:
   - a játék telepítését
   - a frissítéseket
   - az indítást

---

# ⚠️ Fontos

- A játék jelenleg **nem rendelkezik teljes frontenddel**, ezért használata korlátozott.
- A launcher **fejlesztés alatt áll**, nem tekinthető végleges verziónak.
